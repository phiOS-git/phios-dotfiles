# phiOS — the generation contract.
#
# One row per themed target. Four fields separated by `|`, whitespace around
# each field is trimmed, `#` starts a comment, blank lines are ignored.
#
#   template  | destination | reload | class
#
#   template     path from the repository root
#   destination  path relative to $HOME, matching the installer's convention
#   reload       command that makes a running instance pick the file up, or
#                `-` when the target has no reload path at all
#   class        A hot reload  |  B runtime reconfiguration  |  C restart
#
# `phi theme` consumes this file: render, set, preview, list and check all
# resolve tokens through it, and it owns the reload mechanics.
# `phios-render` takes an explicit template path and `phios-install` walks
# `profiles/*/templates/` directly, so neither needs the destination column.
#
# `[unknown]` means a reload path exists but is not wired. It is never to be
# guessed at: a wrong reload command fails silently — the file is written,
# the application keeps its old colours, and nothing reports it. Such a row
# is rendered and reported as not yet wired, never skipped.
#
# A row here must point at a template that exists; a row without one cannot
# be rendered. Some themed targets deliberately have no row — see the notes
# at the end of this file.

# nothing can push a new one into it. New shells pick it up, so class C with a
# restart that costs nothing.

# phi-shell. Reload is `-` because Quickshell watches every QML file it has
# loaded and hot-reloads on change. The destination assumes phi-shell is
# checked out at exactly ~/.config/quickshell/phi, the one path `qs -p` and
# Quickshell's named-config lookup both resolve without an override.
profiles/desktop/templates/.config/quickshell/phi/Config/Tokens.qml.tmpl | .config/quickshell/phi/Config/Tokens.qml | -         | A

# The colour half, split out of Tokens.qml: this file changes on every variant
# switch, that one does not. Config/Colors.qml watches this JSON itself, so no
# external command is needed — and because plain JSON is not a QML singleton's
# own source, rewriting it updates a FileView's content rather than forcing
# Quickshell's singleton-reload path.
profiles/desktop/templates/.config/quickshell/phi/Config/Colors.json.tmpl | .config/quickshell/phi/Config/Colors.json | -         | A

# --- themed targets with no row --------------------------------------------
#
# Librewolf's userChrome.css has a real template but no row: a Firefox profile
# directory carries a random 8-character prefix generated at first launch
# (~/.librewolf/<random>.default-release/chrome/), which this file's plain
# template->destination mechanism cannot express. Resolving it means reading
# ~/.librewolf/profiles.ini's Path= key. Still open.
#
# The Linux VT console palette has no row for a different reason: `setvtrgb`
# wants bare 0-255 decimal triples and this pipeline only ever emits #rrggbb.
# profiles/base/system/etc/phi/console.palette carries the values literally,
# traced to PHI_ANSI_*; it is a manual re-sync on a palette change.
