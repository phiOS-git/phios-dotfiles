# workstation

`zotac`. The counterpart of `laptop`: a machine that is always on mains, has no
battery, no backlight and no touchpad, and drives external monitors.

Empty. Everything it will eventually hold — the monitor layout of ADR 077, the
"no power saving" defaults — is owned by the settings panel and by profiles
that do not exist yet, and nothing on `zotac` is configured by hand today that
would belong here. It is declared in `hosts/zotac.txt` from S-03 so that the
place exists before something needs it, which is cheaper than discovering the
gap later.
